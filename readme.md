# TypeScript Basics

Aqui reúno os exercícios e exemplos que faço enquanto estudo TypeScript. Vou adicionando os arquivos conforme aprendo novos conceitos e testo como funcionam na prática.

Começo com exemplos básicos e, aos poucos, avanço para coisas mais completas.

## Conteúdos

- Variáveis e tipos
- Condições e repetições
- Funções
- Arrays
- Objetos e interfaces
- Union types

## Organização

Cada arquivo tem um exemplo separado, com comentários para me ajudar a revisar o que estudei.

## Como executar

Instale o TypeScript:

    npm install --save-dev typescript

Compile os arquivos:

    npx tsc

Execute um exemplo:

    node dist/01-ola-mundo.js
